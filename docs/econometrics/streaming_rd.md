# Full-source replay regression discontinuity

`rdrobust` can fit a replayable `Dataset` without collecting its observation matrix. Sharp and fuzzy local-polynomial effects, the conventional estimate, bias-corrected estimate and robust bias-corrected variance use every positive-kernel-weight row on the appropriate side of the cutoff. The returned diagonal covariance describes three alternative reports of one effect; it does not assert independence between these reports.

The adapter supports triangular, Epanechnikov and uniform kernels; separate left/right `h` and `b`; `rho`; polynomial orders `p` and `q > p`; nearest-neighbor and HC0–HC3 residual rules; and one declared cluster variable. It implements the existing model's five MSE selectors (`mserd`, `msesum`, `msetwo`, `msecomb1`, `msecomb2`) and their CER counterparts, regularization, bandwidth restriction and sharp/fuzzy bandwidth equation selection. The default NN/MSE fit is supported. These selectors replay the full source and do not select bandwidths on a reporting sample.

Numerical fits use float64 Torch, scaled polynomial bases and a global TSQR reduction. Running-value ties, exact side counts, order-statistic pilot quantiles and complete nearest-neighbor windows are stored in owned SQLite storage. Neighbors include the complete tied blocks; bounded vectorized halos preserve the same residuals across source partitions. Cluster score sums also spill to disk. Fuzzy inference retains outcome/treatment covariance and the first-stage delta method.

Covariate-adjusted RD is not implemented by the underlying native model. This adapter does not add that feature, weights, multiple cluster dimensions or bootstrap/uniform-band inference. Rank, weak first stage, insufficient local residual degrees of freedom, changing source, unavailable temporary storage and unrepresentable float64 operations cause explicit failures.

The workspace plan bounds numerical blocks, factors, decoded group metadata, cluster caches and the NN halo before their allocation. Metadata and neighbor windows require disk space proportional to distinct running values and selected bandwidths; global scans and automatic bandwidth selection add computation. There is no total-row ceiling below exact float64 counts, but speed and feasible size depend on model width, disk, neighborhood size and hardware. This is not a promise that arbitrary data volumes fit on every computer. At most 400 original rows enter the reporting metadata, never the estimator or variance.

Verification covers fixed asymmetric bandwidths, the default automatic NN selector, all MSE selectors, representative CER selectors, sharp/fuzzy designs, clustered ties, polynomial orders, missing values, source mutation, resource refusal and original-unit/permutation invariance. An independent NumPy matrix oracle verifies local-polynomial robust bias correction; NumPy is used only in tests. Saved results round-trip through JSON and produce the standard publication-table LaTeX.
